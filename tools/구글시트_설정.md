# 구글시트 연동 — 처음 한 번만

30분쯤 걸립니다. 순서대로만 하면 됩니다.

---

## 1 · 시트 만들기

1. [sheets.new](https://sheets.new) 로 새 스프레드시트를 만듭니다.
2. 이름을 아무거나 붙입니다 (예: `학습기록`).
3. 시트 안에서 **확장 프로그램 → Apps Script**.

## 2 · 스크립트 붙여넣기

1. 편집기에 있던 `function myFunction() {}` 를 **전부 지웁니다.**
2. `tools/appsscript_academy.gs` 내용을 **통째로** 붙여넣습니다.
3. 저장 (⌘S).

## 3 · 배포

1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴 → **웹 앱**
3. 설정:
   - 실행할 사용자 : **나**
   - 액세스 권한이 있는 사용자 : **모든 사용자**
4. **배포** → 권한 승인 (Google 경고 화면이 나오면 *고급 → 이동*)
5. 나온 **웹 앱 URL** 을 복사합니다. `.../exec` 로 끝납니다.

> ⚠ 액세스 권한이 "모든 사용자" 가 아니면 저장이 **405 로 조용히 실패**합니다.
> 화면에는 저장된 것처럼 보이는데 시트에는 아무것도 안 올라갑니다.

## 4 · 표 만들기

편집기 위쪽 함수 드롭다운에서 **`tpSetup`** 을 고르고 **실행(▶)**.

`실행 로그` 에 표 8개가 만들어졌다고 나오면 됩니다.

```
학원 · 일정 · 과제 · 학습기록 · 피드백 · 성적 · 목표 · settings
```

## 5 · 사람 등록 — **여기가 격리의 전부입니다**

시트로 돌아가 `settings` 탭을 엽니다.

```
      A            B              C
1   공용코드    family-2026      ← 아무 문자열. 1차 관문입니다
2   명단 사용   켬               ← 반드시 "켬"
5   이름        역할            개인코드     ← 헤더 (건드리지 마세요)
6   (아이 이름)   아이            (아이만의 코드)
7   (부모 이름)   부모            (부모만의 코드)
8   (선생 이름)   선생            (선생만의 코드)
```

- **역할** 칸에는 `아이` / `부모` / `선생` 중 하나를 적습니다.
- **개인코드는 셋 다 달라야 합니다.** 같으면 서로의 데이터가 보입니다.
- 비워두면 공용코드로 통과해서 — 역시 격리가 안 됩니다.

편집기에서 **`tpRosterAudit`** 을 실행하면 이 셋을 점검해줍니다.
`문제 없음` 이 뜰 때까지 고치세요.

```
공용코드 : 설정됨
명단 : 켬 · 3명
등재 : (아이)(child), (부모)(parent), (선생)(teacher)
문제 없음. 세 사람의 코드가 모두 다르고 역할이 채워져 있습니다.
```

## 6 · 앱에 주소 넣기

`config.json` 을 열어 3번에서 복사한 URL 을 넣습니다.

```json
{
  "url": "https://script.google.com/macros/s/AKfyc…/exec",
  "code": "family-2026"
}
```

`code` 는 `settings` B1 과 똑같이 맞춥니다.

## 7 · 배포

GitHub 저장소를 만들고 `index.html` 과 `config.json` 을 올린 뒤
**Settings → Pages → Branch: main / root**.

1~2분 뒤 `https://<계정>.github.io/<저장소>/` 로 열립니다.
폰 사파리/크롬에서 열고 **홈 화면에 추가** 하면 앱처럼 씁니다.

## 나중에 바꿀 때

| 하고 싶은 것 | 하는 법 | 재배포 |
|---|---|---|
| 공용코드 변경 | `settings` B1 셀 + `config.json` | 불필요 (30초 캐시) |
| 개인코드 변경 | `settings` C열 셀 | 불필요 |
| 사람 추가 | `settings` 6행 아래에 이름·역할·코드 | 불필요 |
| 사람 차단 | 그 사람 행을 지웁니다 | 불필요 |
| 스크립트 수정 | 붙여넣기 → 저장 → **배포 → 배포 관리 → 연필 → 버전: 새 버전** | 필요 |

> 스크립트를 다시 올린 뒤에는 **`tpSetup` 을 한 번 실행**하세요.
> 안 그러면 요청마다 설치 검사가 돌아 느려집니다.

## 확인용 함수

편집기 함수 드롭다운에서 실행하고 `실행 로그` 를 봅니다.

| 함수 | 하는 일 |
|---|---|
| `tpSetup()` | 표 8개 생성·서식 고정. 값은 한 글자도 안 건드립니다 |
| `tpVersion()` | 라이브에 올라간 버전 확인 |
| `tpRosterAudit()` | 명단 점검 — 코드 중복·역할 누락을 잡아냅니다 |
| `tpRosterInit()` | 명단 뼈대 3줄을 넣어줍니다 (그 뒤 시트에서 직접 수정) |

## 안 될 때

| 증상 | 원인 |
|---|---|
| `명단이 꺼져 있습니다` | `settings` B2 가 `켬` 이 아님 |
| `공용코드가 설정되지 않았습니다` | `settings` B1 이 비어 있음 |
| `역할이 지정되지 않았습니다` | 그 사람의 역할 칸이 비었거나 오타 |
| `명단에 없는 이름입니다` | 이름이 시트와 정확히 같아야 함 (공백 주의) |
| `서버가 응답하지 않습니다` | 콜드스타트. 20초 기다렸다 한 번 더 |
| 저장은 되는데 시트가 빔 | 배포 액세스 권한이 "모든 사용자" 가 아님 |

## 지역 시험 (연동 전에 동작만 보고 싶을 때)

```bash
python3 tools/fake_sheet_server.py --port 8787 --fast
```

`config.json` 의 url 을 `http://127.0.0.1:8787/exec` 로 바꾸고
`http://127.0.0.1:8787/index.html` 을 엽니다.

시험용 계정 — 민준/`child-pw` · 어머니/`parent-pw` · 권민영/`teacher-pw`

`--fast` 를 빼면 실제 Apps Script 처럼 웜 2.6초 / 콜드 15초로 굼떠집니다.
동기화가 정말 버티는지 보려면 이쪽으로 하세요.
