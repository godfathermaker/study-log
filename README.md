# 학습 기록 — 과외 학생 관리 웹앱

과외 학생이 여러 학원을 다니는데 **학원 일정 / 과제 / 실제로 한 공부 / 학원 피드백**이
흩어져 있어 "계획 대비 뭘 했나"를 아무도 못 보는 문제를 풉니다.

핵심 가치는 **누적**입니다. 3개월 뒤에 "5월엔 수학 학원 주 6시간에 자습 2시간이었고
피드백에 '숙제 미제출'이 4번 나왔다"를 볼 수 있어야 합니다.
그래서 스키마의 모든 결정이 *과거 기록이 깨지지 않는가*를 기준으로 갑니다.

```

      │  GET = JSONP · POST = no-cors + text/plain (preflight 회피)
      ▼

      ▼
Google Sheet (8 탭)
```

**localStorage 가 1차 저장소, 시트는 동기화 계층.** 백엔드가 죽어도 앱은 동작합니다.

## 보호선은 하나다 — 아이는 어른들의 기록을 못 본다

계정은 셋. 이름도 개인코드도 각각 다릅니다.
공용코드가 1차 관문이고, **개인코드가 역할을 결정**합니다.

**부모와 선생은 같은 것을 봅니다.** 둘 다 아이를 함께 관리하는 쪽이니까요.
아이에게만 닫혀 있는 것은 **피드백과 성적** — 어른들이 아이에 대해 쓴 말입니다.

| 데이터 | 아이 | 부모 | 선생 |
|---|---|---|---|
| 학원 · 학교 · 일정 | 읽기 | 쓰기 | 쓰기 |
| 과제 | 쓰기 | 쓰기 | 쓰기 |
| 학습기록 | 쓰기 | **읽기** | 읽기 |
| **피드백 원문** | **차단** | 쓰기 | 쓰기 |
| **성적** | **차단** | 쓰기 | 쓰기 |
| 이번 달 목표 | **읽기** | 쓰기 | 쓰기 |
| 분석 화면 | — | 있음 | 있음 |

학습기록은 부모·선생이 **읽기만** 합니다. 아이가 쓴 것이니 어른이 고치지 못합니다.

### 격리는 서버에서 한다 — 이게 이 앱의 핵심 구현 조건

화면에서 숨기는 것은 격리가 아닙니다. 클라이언트가 전체를 받아놓고 CSS 로 가리면
개발자도구·페이지소스·네트워크탭 어디로든 다 읽힙니다.

그래서 `doGet` 이 개인코드로 역할을 판정하고 **그 역할이 볼 수 있는 시트만 읽습니다.**
아이 세션의 응답에는 `피드백`·`성적` 키가 **아예 존재하지 않습니다.**

실측으로 확인했습니다:

```
아이 코드로 위조 POST      {"ok":true,"n":2,"denied":2}
                           피드백·성적은 거부. 학습기록·과제만 통과
부모 코드로 학습기록 위조   {"ok":true,"n":1,"denied":1}
                           부모는 읽기만 — 아이 기록을 못 고친다

받는 표
  아이   과제 목표 일정 학습기록 학원
  부모   과제 목표 성적 일정 피드백 학습기록 학원
  선생   과제 목표 성적 일정 피드백 학습기록 학원
         ^ 부모와 선생이 완전히 같다. 아이만 피드백·성적이 빠진다
```

⚠ 한계: **아이가 부모 개인코드를 알아내면** 부모 계정으로 들어갈 수 있습니다.
코드는 따로 관리하시고, 정말 민감한 내용은 이 앱에 적지 마세요. 가족 내부용 수준입니다.

⚠ `authOK_` 는 **fail-closed** 입니다 (CPX 와 정반대).
명단을 못 읽으면 아무도 통과 못 합니다. 역할을 모르는 채 통과시키면
아이가 부모 데이터를 받아가기 때문입니다.

## 과거를 깨뜨리지 않기 위한 두 가지 결정

### 1 · 학원을 삭제하지 않는다

`상태='종료'` 묘비를 세웁니다. 삭제하면 3개월치 학습기록·피드백·성적의
`학원rid` 가 전부 고아가 됩니다 — "무슨 학원이었는지 모르는 기록"이 됩니다.

### 2 · `일정` 에 유효기간이 있다

시간표를 바꾸면 옛 행을 **어제까지로 닫고 새 행을 오늘부터** 엽니다. 고치지 않습니다.

```
시간표 변경 전 : 8/19 15:30-17:30 · 오늘 15:30-17:30 · 9/2 15:30-17:30
시간표 변경 후 : 8/19 15:30-17:30 · 오늘 10:00-12:00 · 9/2 10:00-12:00
                 ^^^^^^^^^^^^^^^^ 과거는 그대로

시트에 남는 것
  1요일 15:30-17:30 [2026-06-01 → 2026-08-25]
  1요일 10:00-12:00 [2026-08-26 → 현재]
```

유효기간이 없으면 시간표를 한 번 바꿀 때마다 **과거 일과표가 전부 소급 재작성**됩니다.
누적 데이터가 통째로 거짓말이 됩니다.

## 동기화 — CPX 에서 실제로 겪은 것들

`~/claude/cpx-flashcards-web/` 의 하드닝을 이식했습니다.
아래는 전부 그쪽에서 데이터를 날렸던 경로입니다.

| 장치 | 없으면 생기는 일 |
|---|---|
| 부팅·온라인복귀·탭복귀·2분주기 `retryPending()` | **영구 손실.** 탭 닫힘→비콘 락 경쟁→전량 폐기→재접속해도 재전송 주체가 없음 |
| 청크 **순차** 전송 (`Promise.all` 금지) | 동시 발사가 자기 자신과 락 경쟁 |
| 확인을 **응답 도착 기준**으로 | 고정 타임아웃은 서버보다 빨라 헛경고 |
| `AUTH_WAIT = 25000` | 콜드스타트 13~21초. 아침 첫 접속이 항상 콜드 |
| 1.2초 코얼레싱 + 8초 상한 | 항목마다 POST 하면 저장이 16초→37초 |
| **오프라인이면 판정 안 함** | 지하철에서 빨간 경고 |
| 모든 행에 클라이언트 생성 `rid` · 업서트 | no-cors 라 성공을 모름 → 재전송이 전부 중복 행이 됨 |
| 늦게 온 JSONP 용 무덤 함수 | `is not defined` 로 죽으며 pend 정리 유실 |
| localStorage 키에 **역할** 포함 | 기기 공유 시 앞사람 캐시가 다음 사람에게 보임 |

### 실측 (가짜 시트 서버 + Chromium)

```
영구 손실 재현    POST 전량 폐기 → 로컬 3건 / 서버 0건 / pend 3 / "3건 미확인"
        복구      서버 정상화 후 재접속, 아무것도 안 누름
                  → 6초 만에 서버 3건 · pend 0 · 중복 0
                  (CPX 는 이 상황에서 3분을 방치해도 그대로였다)

바뀐 열만 전송    신규 행 = 5열 / 그 뒤 상태만 고침 = 1열  (선을 넘어가는 것을 가로채 확인)
기회 소진 복구    tries=5 로 자동 재전송이 포기 → "지금 동기화" 누르면 복구
어른 코드 저장    tp_me 의 code 가 빈 문자열 (아이 계정만 자동 로그인)
구버전 캐시       아이 캐시에 피드백을 심고 pull → 메모리·localStorage 양쪽에서 사라짐
기기 저장 실패    setItem 이 던지게 만들면 "이 기기에 저장하지 못했습니다" 가 뜬다
자정 넘는 일정    23:00–00:30 은 저장 거부 + 두 줄로 나누라고 안내
숫자 오타         −30 / 99999 저장 거부, 50 은 통과
작성자 보존       선생이 낸 과제를 아이가 완료 체크 → 작성자는 선생 그대로
연속 입력 20건    POST 1회 · 버려짐 0 · 중복 0 · 누락 0
24초 쉼없이 30건  첫 POST 8.5초(상한 작동) · 총 3회 · 누락 0
오프라인 쓰기     칩이 "오프라인 · 1건 대기" (빨간 경고 아님)
        복귀      자동 전송 · 중복 0
콜드스타트 15초   로그인 성공 (AUTH_WAIT 25초가 견딤)
시간표 변경       과거 그리드 불변 · 시트에 옛 행/새 행 공존
학원 종료         과거 기록의 학원명 유지 · 미래 그리드에서만 사라짐
```

### 탭 2 · 학원
**학교도 학원과 똑같은 행입니다.** 이름과 시간만 다릅니다 — 따로 만든 개념이 없습니다.
추가 시트 맨 위에 빠른 시작 버튼이 있습니다:

```
[학원]  이름만 채우고 시간 직접 입력
[학교]  이름=학교 · 회색 · 월~금 08:20–15:00 을 한 번에 채움
[과외]  이름만 채우고 시간 직접 입력
```

누른 뒤 이름·시간을 고치면 됩니다. **학교를 넣어야 빈 시간이 맞습니다** —
안 넣으면 학교에 있는 시간까지 "빈 시간 9시간"으로 셉니다.
`종료` 버튼은 삭제가 아닙니다.

### 탭 3 · 피드백·목표 (부모·선생)
이번 달 목표 + 진행 게이지.
**카톡 원문을 그대로 붙여넣으면** 날짜·학원·태그·감성을 추측해 폼으로 세웁니다.

> **자동 분류를 그대로 저장하지 않습니다.** 고칠 수 있는 폼으로 띄우고 확인받은 뒤에만
> 저장하며, 원문은 언제나 통째로 보존합니다. 자동 태그가 틀린 채 3개월 쌓이면
> 분석이 전부 오염되고 되돌릴 방법이 없습니다.

### 탭 4 · 분석 (부모·선생)
KPI 5개 + 차트 5개. 전부 인라인 SVG, 외부 라이브러리 없음.

1. 계획 대비 실제 (수업 시간 ↔ 자습 기록)
2. 과목별 자습 시간
3. 과제 완료율 (마감 넘긴 건수 포함)
